# Creating a sign-off sheet
<span data-uuid="732ef261-1e24-4799-aa02-d09a01665c83" style="display:none"></span>

A printable sign-off sheet can be generated in-system which can be used for briefings/toolbox talks.

**Follow the steps below to create a sign-off sheet.**

!!! step

    <span data-uuid="231a5aad-7e1f-4220-b0fd-dbf0e12f5893" style="display:none"></span>

    From [My Dashboard](https://cloud.opus-safety.co.uk/dashboard), click on **Pick workspace** and select the site where you wish to create the sign-off sheet.

    <span data-uuid="252fdcd5-0244-411e-87d6-b99571dbc75e" style="display:none"></span>
    ![](../assets/media/occ-captures/dashboard/pick-workspace-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/dashboard/pick-workspace-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

    !!! tip

        <span data-uuid="c39115fa-f669-46bc-aa16-6e3d9abec11f" style="display:none"></span>
        If the employees you wish to include cover multiple sites - select the highest common parent site, such as a regional or company parent.

!!! step

    <span data-uuid="6722fb3b-6409-466e-8ac4-f68fa0fe7ecc" style="display:none"></span>

    From the site inbox, click the **Switch to Manage Mode** button.

    <span data-uuid="ee87e4ba-ec6f-4e10-af5b-7aee6010ee71" style="display:none"></span>
    ![](../assets/media/occ-captures/sites/uuid/switch-to-manage-mode-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/sites/uuid/switch-to-manage-mode-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

!!! step

    <span data-uuid="1fc3c844-7a83-408c-9223-386c61678271" style="display:none"></span>

    Expand the **Employee records** drop-down in the manage sidebar and select **Briefings & Sign-off sheets**.

    <span data-uuid="e87d6665-9f79-4bff-aae2-08bc38998247" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/dashboard/employee-records-a-toggle-briefings-and-sign-off-sheets-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/dashboard/employee-records-a-toggle-briefings-and-sign-off-sheets-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

!!! step

    <span data-uuid="06be43ed-3f58-4c31-a96a-a51b99dc250e" style="display:none"></span>

    Click **New briefing**.

    <span data-uuid="5f5aceb1-217b-4feb-a4c8-445badfaff63" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new-briefing-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new-briefing-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

!!! step

    <span data-uuid="b047dda9-b62d-42d7-9ca5-d042e4b5c9b4" style="display:none"></span>
    Click **Continue** under Sign-off sheet.

    <span data-uuid="c6085dd5-1f8e-4f99-921f-f92812e9c16b" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/role-requirements/new/sign-off-sheet-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/role-requirements/new/sign-off-sheet-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

!!! step

    <span data-uuid="b80d054a-7d0e-4cb4-a274-00ba6d67ce07" style="display:none"></span>
    If applicable, re-select where you would like to create this sign-off sheet.

    Click **Continue**.

    <span data-uuid="2ccd862e-94fd-49ef-83c2-f15525380401" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/demo-company-z-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/demo-company-z-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

!!! step

    <span data-uuid="894b99a2-f6b2-4b0f-bb20-33f62b33c81c" style="display:none"></span>
    Enter a title for the sign-off sheet.

    *This is typically the name of the briefing / training / toolbox talk you're looking to give.*

    <span data-uuid="0fe2c74d-a6f2-4b36-8cfa-8217010f99e1" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/title-light-mode.png#only-light){ style="border-radius: 8px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/title-dark-mode.png#only-dark){ style="border-radius: 8px" loading=lazy }

!!! step

    <span data-uuid="0dc6bf45-135b-4ab2-8709-5edfc180ed5e" style="display:none"></span>
    Select the employees that will be taking part in the briefing / training / toolbox talk and therefore to include on the sign-off sheet.

    *You can select via roles, or per employee.*

    <span data-uuid="93bd856a-55de-46b9-8581-2b06773024b6" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/role-light-mode.png#only-light){ style="border-radius: 8px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/role-dark-mode.png#only-dark){ style="border-radius: 8px" loading=lazy }

!!! step

    <span data-uuid="b0c19613-565c-4025-a7c7-682c7ceb25d2" style="display:none"></span>
    Click **Generate sheet**

    <span data-uuid="05afe975-2da1-4f0c-9540-082fd1ad44ce" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/generate-sheet-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new/generate-sheet-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

!!! step

    <span data-uuid="df2a480f-6490-4d5f-bcf0-31f8dfa7c710" style="display:none"></span>
    On the following page, you can print off the sign off sheet by clicking **Print**

    <span data-uuid="536ad129-f837-4069-9b2f-67bcc7bbe8dd" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/uuid/print-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/uuid/print-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

## Converting to a briefing
<span data-uuid="2ec66bf8-563c-4821-b49c-949ea923ee08" style="display:none"></span>

Sign-off sheets can be converted into Briefings within 10 days of creation by selecting **Convert to briefing** on the sign-off sheet page.
