# Uploading a Briefing
<span data-uuid="326a5229-a048-4ba5-8696-b7fbe664b506" style="display:none"></span>

A briefing is a record of an ad-hoc training, such as a toolbox talk. Briefings allow you to upload proof of training (e.g. via a sign-off sheet) in bulk.

!!! warning

    <span data-uuid="31c84be8-2a73-40b0-b06c-588e11752dee" style="display:none"></span>
    This guide assumes the briefing / toolbox talk has already taken place and explains how to upload the record to Opus Compliance Cloud.

    If it hasn't taken place yet and you need to create a printable sign-off sheet first, follow the guide below.

## Creating the briefing and uploading the record
<span data-uuid="ab1cc111-4652-4a6b-9528-4ff6f008eb4f" style="display:none"></span>


!!! step

    <span data-uuid="68540d4b-c86c-4d83-b19c-91174814469c" style="display:none"></span>
    From [My Dashboard](https://cloud.opus-safety.co.uk/dashboard), click on **Pick workspace** and select the site where you wish to create the briefing.

    <span data-uuid="3fbd6de1-f184-48a1-89ca-5d6c056aa004" style="display:none"></span>
    ![](../assets/media/occ-captures/dashboard/pick-workspace-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/dashboard/pick-workspace-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

    !!! tip

        <span data-uuid="1796b06d-e668-47f5-870d-d2b002f9d950" style="display:none"></span>
        If the briefed employees cover multiple sites - select the highest common parent site, such as a regional or company parent.

!!! step

    <span data-uuid="a3babbb5-6cb0-4f97-aecf-374e94cc01ed" style="display:none"></span>

    From the site inbox, click the **Switch to Manage Mode** button.

    <span data-uuid="97ca6c3a-25f3-4113-9975-01b0c4dcc147" style="display:none"></span>
    ![](../assets/media/occ-captures/sites/uuid/switch-to-manage-mode-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/sites/uuid/switch-to-manage-mode-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

!!! step

    <span data-uuid="fa78e45a-8bd1-48ff-8864-d7be7f49defb" style="display:none"></span>
    Expand the **Employee records** drop-down in the manage sidebar and select **Briefings & Sign-off sheets**.

    <span data-uuid="70bec3fb-7ff2-4cbf-ae9c-fc932fd4bc53" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/dashboard/employee-records-a-toggle-briefings-and-sign-off-sheets-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/dashboard/employee-records-a-toggle-briefings-and-sign-off-sheets-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

!!! step

    <span data-uuid="dd685bd0-f230-4d41-b58c-906cab2ae5aa" style="display:none"></span>
    Click **New briefing**.

    <span data-uuid="0d0773dd-15f8-48e9-91bc-5279aedccfc3" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new-briefing-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/safety-briefings/new-briefing-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

!!! step

    <span data-uuid="8bf1cd2e-5c5b-4d0f-98f1-5d131cfb2b5e" style="display:none"></span>
    Click **Continue** under Briefing.

    <span data-uuid="f0e9b0f2-b346-46f3-9616-ca8528cc5c1f" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/role-requirements/new/briefing-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/employees/role-requirements/new/briefing-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

!!! step

    <span data-uuid="541a5544-f26b-4ec5-9978-a5a9554f84c1" style="display:none"></span>
    Give the briefing a title and configure the rest of the options.

    <span data-uuid="c966b08e-db01-40d1-b766-eb3a7d4c087b" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/title-and-severity-light-mode.png#only-light){ style="border-radius: 8px" width="500" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/title-and-severity-dark-mode.png#only-dark){ style="border-radius: 8px" width="500" loading=lazy }

!!! step

    <span data-uuid="140294e7-2bdf-44b9-80be-34aa3911fd46" style="display:none"></span>
    Upload the briefing / training / toolbox talk record and input the date of the training

    <span data-uuid="785578e9-dff2-4be8-92ec-715764216116" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/upload-a-file-light-mode.png#only-light){ style="height: 500px; border-radius: 8px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/upload-a-file-dark-mode.png#only-dark){ style="height: 500px; border-radius: 8px" loading=lazy }

    !!! warning "Important!"

        <span data-uuid="4b1c89ec-84f8-40fc-924d-4580c5ce9fdb" style="display:none"></span>
        **Date of training (completion or certificate date)** is the date the the briefing / training / toolbox talk was given.

!!! step

    <span data-uuid="a14bdf85-af2b-4643-901d-61b6389e8ff0" style="display:none"></span>
    Select the employees that took part in this briefing. You can select via roles, or per employee.

    <span data-uuid="c7914d06-03af-4c52-b1dd-f4b7347f9b30" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/role-light-mode.png#only-light){ style="border-radius: 8px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/role-dark-mode.png#only-dark){ style="border-radius: 8px" loading=lazy }

!!! step

    <span data-uuid="4d7fa524-c3d6-4081-a447-d8483d748573" style="display:none"></span>
    Click **Save briefing**

    <span data-uuid="5ac1ed40-0d01-4357-a804-a303be0937fe" style="display:none"></span>
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/save-briefing-light-mode.png#only-light){ style="height: 50px" loading=lazy }
    ![](../assets/media/occ-captures/admin/sites/uuid/templates/trainings/new/save-briefing-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }
