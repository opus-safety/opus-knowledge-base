# Subscriptions
<span data-uuid="ea89b15a-ec64-40ba-acc1-6849beb33c19" style="display:none"></span>

<span data-uuid="76d2d1a4-4687-43a5-85df-51a6f58a83a7" style="display:none"></span>
In Opus Compliance Cloud, you can configure your account to notify you when certain events happen, such as reminders when your e-learning is due or notifications when incidents occur. We call these **subscriptions**.

## How do subscriptions work?
<span data-uuid="d60b9714-c931-402b-8655-c2db053d693f" style="display:none"></span>

<span data-uuid="8da1aa6c-d4cf-41bb-89fa-d83b109483ec" style="display:none"></span>
When a task is created, Opus Compliance Cloud checks whether you're subscribed to that kind of task. If you are, you will receive a **notification**. There are three ways the system can notify you:

<span data-uuid="80888f5d-4e4b-475e-9715-73f014990f34" style="display:none"></span>

| Type | Description |
| :--- | :--- |
| <span class="mb-label mb-label-slate">:lucide-bell-ring: In-system notification</span> | Appears in Opus Compliance Cloud, under the bell icon and on the notifications page. |
| <span class="mb-label mb-label-olive">:lucide-mail: Direct email notification</span> | An email sent directly to notify you when a task-related event occurs. Ideal for keeping up to date with important events, such as incidents. |
| <span class="mb-label mb-label-mauve">:lucide-mails: Digest email</span> | A single email that collates all your unread in-system notifications. Digest emails run on a **Daily** or **Weekly** schedule. |

<span data-uuid="cd4b5556-013c-4e22-8f97-952b2e19f49d" style="display:none"></span>

### Subscription wizard
<span data-uuid="b69fbe19-0474-4fef-9382-102eeeca1441" style="display:none"></span>

<span data-uuid="8321856e-3984-4a42-afe8-fbc071b8a7ca" style="display:none"></span>
The subscription wizard is a quick way to set up default in-system and email notifications for your account.

All new users go through the wizard when they [create their Opus account](creating-and-linking-your-opus-account.md). Existing users can re-run it at any time from their subscription settings, or with the button below.

### Manually subscribing
<span data-uuid="7badc38c-c6e7-4138-9e84-82618b9042da" style="display:none"></span>

<span data-uuid="d9723a29-ddc9-47d1-8ab2-f637e7a5bfcd" style="display:none"></span>
If you wish to setup/modify your subscriptions manually. You can do this following the steps below.

??? outline "<span class="mb-label mb-label-slate">Manual subscription step-by-step instructions</span>"

    <span data-uuid="ff0be4b7-98bd-480f-bfd9-c5dc4f364256" style="display:none"></span>

    !!! step

        <span data-uuid="4d03e10d-2b33-4943-a437-42a6c3ad5485" style="display:none"></span>

        <span data-uuid="b2139d84-76cf-4b00-8721-bd90e3fd1b14" style="display:none"></span>
        From [My Dashboard](https://cloud.opus-safety.co.uk/dashboard), click on **Pick workspace** and select the site where you would like to subscribe.

        <span data-uuid="9a0c49ea-4e07-4e55-a1e2-f373cf03ec77" style="display:none"></span>
        ![](../assets/media/occ-captures/dashboard/pick-workspace-light-mode.png#only-light){ style="height: 50px" loading=lazy }
        ![](../assets/media/occ-captures/dashboard/pick-workspace-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

        !!! info "Info"

            <span data-uuid="422b26da-a430-4b8b-9c47-54125e39f7d2" style="display:none"></span>

            <span data-uuid="d43435bb-3fc8-4aeb-b9ce-8df29561899e" style="display:none"></span>
            Where you subscribe is **important**. If you have access to multiple sites, subscribing at a particular site will automatically subscribe you to all sub-sites beneath it.

    !!! step

        <span data-uuid="11e98dc1-dbdb-4a6b-b78a-3ccaf25c7314" style="display:none"></span>

        <span data-uuid="a7eca502-9847-41d7-a406-a95937b6e5b3" style="display:none"></span>
        From the tabs at the top, select **Subscriptions**.

        <span data-uuid="1efbdd83-1f01-42b0-a1a1-c40978b2a314" style="display:none"></span>
        ![](../assets/media/occ-captures/sites/uuid/subscriptions-a-z-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
        ![](../assets/media/occ-captures/sites/uuid/subscriptions-a-z-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

    !!! step

        <span data-uuid="18c94ed7-8348-447b-a249-1830bab1ac8a" style="display:none"></span>

        <span data-uuid="cf880c1d-671b-4e3d-81c3-6ed7c988533a" style="display:none"></span>
        Browse the list and select whether you would like to be notified in-system or via email.

        <span data-uuid="87d4759f-5954-4e96-abae-97a86e90f7d1" style="display:none"></span>
        ![](../assets/media/occ-captures/sites/uuid/subscriptions/anything-light-mode.png#only-light){ style="border-radius: 8px" loading=lazy }
        ![](../assets/media/occ-captures/sites/uuid/subscriptions/anything-dark-mode.png#only-dark){ style="border-radius: 8px" loading=lazy }

        !!! warning "The 'Anything' option"

            <span data-uuid="860e5784-e633-44a1-a1be-d650d48c53df" style="display:none"></span>

            <span data-uuid="cfd41f91-2789-45ed-9122-cca8e8d5ddd2" style="display:none"></span>
            At the top of the list, you will find the **Anything** option. Selecting this will subscribe you to notifications for all tasks generated at that site and any sub-sites beneath it.

            Due to the potentially high volume of notifications, this option is only available for in-system notifications. **We recommend being conservative with this option - only enabling it for your personal employee record and/or a single site.**
