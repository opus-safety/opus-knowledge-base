# Notifications
<span data-uuid="de6c9418-e81e-4290-8888-06d546380de8" style="display:none"></span>

<span data-uuid="5805d860-5b4c-42f3-8826-1583f430b803" style="display:none"></span>
In Opus Compliance Cloud, you can configure your account to notify you when certain events happen, such as reminders when your e-learning is due or notifications when incidents occur.

## How do notifications work?
<span data-uuid="bccd4bb2-0ae1-4481-ac93-c77b0b508b34" style="display:none"></span>

<span data-uuid="56f7f462-bcb1-446c-b2c8-4a937e525796" style="display:none"></span>
When a task is created, Opus Compliance Cloud checks whether you're **subscribed** to that kind of task. If you are, you will receive a **notification**. There are three ways the system can notify you:

<span data-uuid="a2d0c401-04ef-4602-8731-edc10920822a" style="display:none"></span>

| Type | Description |
| :--- | :--- |
| <span class="mb-label mb-label-slate">:lucide-bell-ring: In-system notification</span> | Appears in Opus Compliance Cloud, under the bell icon and on the notifications page. |
| <span class="mb-label mb-label-olive">:lucide-mail: Direct email notification</span> | An email notification sent whenever an event occurs. Ideal for getting notified as soon as possible with important events, such as incidents. |
| <span class="mb-label mb-label-mauve">:lucide-mails: Digest email</span> | A single email that collates all your unread in-system notifications. Digest emails run on a **Daily** or **Weekly** schedule. |

??? outline "<span class="mb-label mb-label-emerald">Subscription wizard</span> (recommended)"

??? outline "<span class="mb-label mb-label-yellow">Manually subscribing</span>"

    <span data-uuid="a1bb1e0b-f308-47d4-bbe5-2de9fe67fafd" style="display:none"></span>

    <span data-uuid="7fc76f15-745c-4fdd-bf92-7319a62ab0f7" style="display:none"></span>
    If you wish to setup/modify your subscriptions manually. You can do this following the steps below.

    ??? outline "Manual subscription step-by-step instructions"

        <span data-uuid="856db02d-139a-4be2-adbd-e6f24e956980" style="display:none"></span>

        !!! step

            <span data-uuid="1152a971-a553-45a4-bf7e-0bc202959848" style="display:none"></span>

            From [My Dashboard](https://cloud.opus-safety.co.uk/dashboard), click on **Pick workspace** and select the site where you would like to subscribe.

            <span data-uuid="de4d8a8b-d527-44af-be0c-5a312b81eb8f" style="display:none"></span>
            ![](../assets/media/occ-captures/dashboard/pick-workspace-light-mode.png#only-light){ style="height: 50px" loading=lazy }
            ![](../assets/media/occ-captures/dashboard/pick-workspace-dark-mode.png#only-dark){ style="height: 50px" loading=lazy }

            !!! info "Info"

                <span data-uuid="fa98abd7-959c-4fc1-a3b9-1cfeaffc6093" style="display:none"></span>

                Where you subscribe is **important**. If you have access to multiple sites, subscribing at a particular site will automatically subscribe you to all sub-sites beneath it.

        !!! step

            <span data-uuid="98e42c04-00a8-4f44-b42d-fdee57dd8ff4" style="display:none"></span>

            From the tabs at the top, select **Subscriptions**.

            <span data-uuid="e1a3fbe9-e079-4142-87dc-e8e519887332" style="display:none"></span>
            ![](../assets/media/occ-captures/sites/uuid/subscriptions-a-z-light-mode.png#only-light){ style="border-radius: 8px" width="300" loading=lazy }
            ![](../assets/media/occ-captures/sites/uuid/subscriptions-a-z-dark-mode.png#only-dark){ style="border-radius: 8px" width="300" loading=lazy }

        !!! step

            <span data-uuid="5628120e-f645-4a5f-a842-9859b3e0126a" style="display:none"></span>

            Browse the list and select whether you would like to be notified **in-system** or via **email**.

            <span data-uuid="23869327-fa04-4336-ac68-397ce55c8cb2" style="display:none"></span>
            ![](../assets/media/occ-captures/sites/uuid/subscriptions/anything-light-mode.png#only-light){ style="border-radius: 8px" loading=lazy }
            ![](../assets/media/occ-captures/sites/uuid/subscriptions/anything-dark-mode.png#only-dark){ style="border-radius: 8px" loading=lazy }

            !!! warning "The 'Anything' option"

                <span data-uuid="05ce2417-8ff3-43e5-95e3-15995b6f791d" style="display:none"></span>

                At the top of the list, you will find the **Anything** option. Selecting this will subscribe you to notifications for all tasks generated at that site and any sub-sites beneath it.

                Due to the potentially high volume of notifications, this option is only available for in-system notifications. **We recommend being conservative with this option - only enabling it for your personal employee record and/or a single site.**

        !!! step

            <span data-uuid="dc471d21-799e-497a-8b5f-d1670b7128fe" style="display:none"></span>

            Once you're happy with your configuration, click **Save changes** at the bottom.

            <span data-uuid="bd6b513b-e222-43d5-9eb3-db373801dc59" style="display:none"></span>
            ![](../assets/media/occ-captures/sites/uuid/subscriptions/save-changes-light-mode.png#only-light){ style="height: 50px" loading=lazy }
