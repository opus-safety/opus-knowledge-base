# API support and charges
<span data-uuid="301dc9f8-ef81-4a69-b909-9b2e0f4a427c" style="display:none"></span>

What support is included with API access to **Opus Compliance Cloud**, and which services are chargeable.

For how to authenticate and make a first request, see [Getting started with the API](getting-started-with-the-api.md).

## What is included
<span data-uuid="be3b6563-a314-4a70-b0ac-6bef87626fc8" style="display:none"></span>

<span data-uuid="d180bae3-1934-45dc-85f4-e74aa14e9a01" style="display:none"></span>
API access is included at no extra cost for every client with an active Opus Compliance Cloud subscription.

The API is self-describing: starting from a single entry point, your developers discover the available resources and actions by following links. We provide the guidance and support you need to use the API as it describes itself. If you would like our team's help designing, reviewing or building an integration, that is available as a paid service.

## Included free of charge
<span data-uuid="7f97ca6e-c5de-4228-9cf6-9acd46704557" style="display:none"></span>

<span data-uuid="bfc59bdf-54bb-4dfb-a810-3c2b5c4b674c" style="display:none"></span>

<div class="nowrap-first" markdown>

| Service | What it covers |
| :--- | :--- |
| **API access** | API keys, and use of every resource available through the API. |
| **Getting-started guide** | Authentication, the entry point, and how to navigate the API by following links, with a worked example. See [Getting started with the API](getting-started-with-the-api.md). |
| **Fault support** | Investigating and fixing cases where the API is unavailable, or is not behaving as the API itself describes or as set out in the getting-started guide. |
| **Clarification** | Answering questions about where to find a resource, or what a field, link or error means. |
| **Kickoff call** | One 30-minute call per client to explain how the API works and point you to the right resources. |
| **Change notices** | Advance notice before we remove or rename a link relation or field. |

</div>

!!! warning "URLs may change without notice"

    <span data-uuid="360da22f-ef06-4148-98f6-1feb9a9006da" style="display:none"></span>

    <span data-uuid="d2f68f99-57a1-444f-ac66-46399e968771" style="display:none"></span>
    Change notices cover link relations and fields, not URLs. Integrations should follow links, and should not store or construct URLs.

## Chargeable services
<span data-uuid="ec60ba0b-0e9b-493f-aa90-572cb89b877d" style="display:none"></span>

<span data-uuid="13d0ff84-8495-4819-96f3-0ce4689dd0b9" style="display:none"></span>

<div class="nowrap-first" markdown>

| Service | What it covers |
| :--- | :--- |
| **Integration design** | Advice on how to structure an integration, which resources to use for your process, and how to map your data. |
| **Code and solution review** | Reviewing or debugging your code, scripts or middleware. |
| **Build work** | Developing an integration, or part of one, on your behalf, including a client that navigates the API. |
| **Custom development** | New resources, fields or data formats that are not part of the standard API. |
| **Third-party systems** | Help configuring or troubleshooting the system you are connecting to. |
| **Workshops and training** | Sessions for your developers beyond the kickoff call. |
| **Ongoing maintenance** | Supporting and updating an integration we built for you, after handover. |

</div>

## How chargeable work is arranged
<span data-uuid="e6de20b1-3255-488e-9a8e-f1c60cf2c73a" style="display:none"></span>

<span data-uuid="b6f1cbfe-abb7-440f-a037-ca569448a51c" style="display:none"></span>

1. If a request falls outside the free scope, we will tell you before doing any chargeable work.
2. We will provide a written quote, either as a fixed price or as an estimate at our day rate.
3. Work starts only once you have approved the quote in writing.
