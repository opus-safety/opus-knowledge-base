# API support and charges
<span data-uuid="301dc9f8-ef81-4a69-b909-9b2e0f4a427c" style="display:none"></span>

<span data-uuid="3beadc81-a07c-4040-866f-90eecdf99c2f" style="display:none"></span>
What support is included with API access to **Opus Compliance Cloud**, and which services are chargeable.

## What is included
<span data-uuid="be3b6563-a314-4a70-b0ac-6bef87626fc8" style="display:none"></span>

<span data-uuid="d180bae3-1934-45dc-85f4-e74aa14e9a01" style="display:none"></span>
Access to our API is included at no extra cost for any organisation already paying to use Opus Compliance Cloud.

The API is self-describing: starting from a single entry point, your developers discover the available resources and actions by following links. We provide and support you need to use the API as it describes itself. If you would like our team's help designing, reviewing or building an integration, that may be available as a paid service.

## Our services
<span data-uuid="7f97ca6e-c5de-4228-9cf6-9acd46704557" style="display:none"></span>

<span data-uuid="bfc59bdf-54bb-4dfb-a810-3c2b5c4b674c" style="display:none"></span>

<div class="nowrap-first" markdown>

| Service | Cost | What it covers |
| :--- | :--- | :--- |
| **API access** | <span class="mb-label mb-label-green">Free*</span> | API keys, and use of every resource available through the API. |
| **Documentation** | <span class="mb-label mb-label-green">Free</span> | All available supplementary documentation available on this knowledge base. |
| **Fault support** | <span class="mb-label mb-label-green">Free*</span> | Investigating and fixing cases where the API is unavailable, or is not behaving as the API itself describes or as set out in our documentation. |
| **Clarification** | <span class="mb-label mb-label-green">Free*</span> | Answering questions about resources or errors that are not clearly described by the API itself |
| **Kickoff call** | <span class="mb-label mb-label-green">Free</span> | An initial online meeting to discuss your usage of our API, whether you are interested in any of our additional paid services (below), and answering general initial questions about our API. |
| **In-depth support** | <span class="mb-label mb-label-amber">Chargeable</span> | May include sessions for your developers beyond the kickoff call or regular communication with our support team beyond the free services. |
| **Integration advice** | <span class="mb-label mb-label-amber">Chargeable</span> | Advice on how to structure an integration, which resources to use for your process, and how to map your data. |
| **Build work** | <span class="mb-label mb-label-amber">Chargeable</span> | Developing an integration, or part of one, on your behalf. |
| **Ongoing maintenance** | <span class="mb-label mb-label-amber">Chargeable</span> | Supporting and updating an integration we built for you, after handover. |
| **Custom development** | <span class="mb-label mb-label-amber">Chargeable</span> | New resources, fields or data formats that are not part of the standard API. |

## How chargeable work is arranged
<span data-uuid="e6de20b1-3255-488e-9a8e-f1c60cf2c73a" style="display:none"></span>

<span data-uuid="b6f1cbfe-abb7-440f-a037-ca569448a51c" style="display:none"></span>

1. If a request falls outside the free scope, we will tell you before doing any chargeable work.
2. Depending on the request, it may require a call to discuss.
3. We will provide a written quote, either as a fixed price or as an estimate at our day rate.
4. Work starts only once you have approved the quote in writing.
