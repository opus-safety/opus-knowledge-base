??? improvement "Improvement: Cadence graph overhaul<span class="meta">27th November 2026</span>"

    <span data-uuid="ca8eb053-8e99-4c71-8346-dd8cab569154" style="display:none"></span>

    <span data-uuid="f97c2f8d-2809-4a92-90db-1bcecd2679fa" style="display:none"></span>
    We've overhauled the checklist and playbook cadence graphs to provide significantly more detail about the reminder tasks associated with each submission.

    <span data-uuid="17e29420-5f22-4d0f-bac9-b5b74b08ab53" style="display:none"></span>
    <video src="../assets/media/videos/system-updates/cadence-improvement.mp4" autoplay loop muted playsinline preload="none" style="border-radius: 8px"></video>

    <span data-uuid="ebe2592b-5f12-485e-82c9-05f86d54b8b9" style="display:none"></span>
    **Summary of improvements:**

    1. **Reminder visibility:** Visually identify when reminders were generated and track the number of days a checklist or playbook remained overdue before submission.
    2. **Future forecasting:** Forecast when the next reminder is due to be generated.
    3. **Monthly late-day calculations:** Calculate and report the total number of overdue days for each month.
    4. **Chart export:** Save the chart as a file, making it easy to include in reports and other documentation.
