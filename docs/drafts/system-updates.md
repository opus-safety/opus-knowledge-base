??? feature-release "Feature release: Subscription report<span class="meta">21st August 2026</span>"

    <span data-uuid="31935d7c-7a06-428c-a9ae-7ba62e617261" style="display:none"></span>
    A new **Subscriptions** report page has been released, allowing you to monitor the status of your employees’ subscriptions. This is particularly useful for top-level administrators, helping them ensure that managers are subscribed to the information and updates relevant to their responsibilities.

    The report includes information such as:

    - :lucide-check-circle-2: If any of our default subscription presets are used
    - :lucide-mail: Email digest configuration
    - :lucide-building-2: Which site(s) they're subscribed at
    - :lucide-tag: Which labels they're subscribed to
