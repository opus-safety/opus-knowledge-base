??? improvement "Improvement: New Task Reports Date Filters<span class="meta">22nd October 2026</span>"

    <span data-uuid="a9e2163b-6b5a-4387-aa27-d00730260579" style="display:none"></span>
    2 new date range filters have been added to the Task reports page.

    1. **:lucide-megaphone: Reported at** - When the task was reported/created
    2. **:lucide-check-circle-2: Resolved at** - When the task was last resolved
    These additional options will allow you to filter your task report further than before!
